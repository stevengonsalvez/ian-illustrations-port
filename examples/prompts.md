# Prompt Examples

These prompts can be copied straight into your agent.

## Illustration planning only

```text
Use $ian-xiaohei-illustrations but do not generate images yet.
Analyze where this article is worth illustrating and output a shot list of about 5 images.
For each image spell out:
- Which paragraph it goes after
- The image's theme
- The core idea
- The structure type
- What Blot does in the image
- Suggested elements
- Suggested label words

<paste article>
```

## Article body illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 weird Blot body illustrations for the article below.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, a few red/orange/blue handwritten annotations.
Each image conveys only one core structure; no PPT infographics, no cute cartoons.

<paste article>
```

## Strategy for a long piece

```text
Use $ian-xiaohei-illustrations to build an illustration strategy for this long article.
Don't illustrate evenly — pick only cognitive anchors: the core judgment, input/output loops, before/after contrasts, common pitfalls, handoff paths.
Default 6-8 images. Output the shot list first; do not generate images.

<paste article>
```

## One image for a single idea

```text
Use $ian-xiaohei-illustrations to generate one 16:9 body illustration for this idea:

Trust isn't shouted into existence — it's laid down one piece of evidence at a time.

Make it weird but clean; Blot must carry the core action.
At most 5 short labels.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations to generate one image for "turning one piece of raw material into three kinds of content: traffic, trust, conversion."
Don't draw a formal flowchart, and don't reproduce the old one-fish-many-uses case.
Invent a new low-tech metaphor and let Blot carry the core action.
```

## Edit: remove a title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow / flowchart" title and underline from the top-left corner; keep everything else unchanged.
Do not add any new text or objects.
```

## Edit: make Blot matter more

```text
Use $ian-xiaohei-illustrations — this image's direction is right, but Blot feels decorative.
Keep the core idea and regenerate: make Blot the one actually driving the structure.
A bit weirder, but still pure white, clean, few words.
```

## Generate a style sampler

```text
Use $ian-xiaohei-illustrations to output 5 Blot body illustrations on different themes.
Themes: information overload, product validation, content compounding, the one-person company, building trust.
Generate each one separately; do not collage.
```
