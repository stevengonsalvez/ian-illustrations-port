# Composition patterns and originality rules

## Base structure types

Pick one structure; don't mix too many.

### Workflow process

Good for: input -> process -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Blot or a weird machine processing in the middle, output on the right, orange arrows expressing the main flow.

### System fragment

Good for: information sources, filters, databases, renderers, a fragment of an agent system.

How to draw: only draw 3-5 core modules, with Blot taking part in one key action.

### Before/after contrast

Good for: chaotic/orderly, manual/automatic, scattered/converged, anxious/stable.

How to draw: chaos on the left, stability on the right, orange arrow in the middle. The character can be more exaggerated.

### Role state

Good for: user pain points, creator state, too many tools, information anxiety, stuck-to-running.

How to draw: 2-4 small states, one short label per state.

### Concept metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automated daily report.

How to draw: one big weird object or machine, a few inputs, one output. Make it memorable.

### Method layering

Good for: methodology frameworks, system layers, capability stacks, content-system layering.

How to draw: box upon box, not a formal pyramid; Blot hauling bricks or building beside it.

### Map route

Good for: from idea to launch, user path, content handoff path, learning path.

How to draw: one winding path, a few nodes, Blot leading the line or walking.

### Mini comic panels

Good for: failure-to-success, the real process, a rant, before/after use.

How to draw: 2-4 small scenes, each panel expressing only one action.

## How to generate an original metaphor

Reinvent the metaphor from the current article every time; never copy old images.

### Three steps

1. Swap the abstract concept for a physical action: stuck, dropped, made heavier, sorted, settled, fermented, opened a door, folded, unpacked, flowed back.
2. Swap the system structure for a low-tech object: a broken machine, cardboard box, drawer, water pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Let Blot carry the action: not standing beside it, but stuck inside the machine, pulling the wrong line, guarding the gate, hauling, patching, weighing, holding the ladder, recording, stuffing something into some weird device.

### Usable object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of string, sluice gate, turntable, black box, hole punch, pasta press, clothesline, weird workstation.
- Pick only 1-2 at a time; don't pile them up.

### Blot action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, mark, recycle.
- The action should serve the core idea; don't be weird just to be weird.

## Anti-copy rules

Do not open or reproduce `assets/examples/` by default. These images are only for style calibration — line density, white space, color restraint, Blot's temperament.

Unless the user explicitly says "follow this one / reproduce this composition / edit using this case," do not directly reuse these old compositions:

- Conveyor with two breakpoints
- Blot pulling a judgment lever inside the content machine
- Blot becoming a funnel sorting traffic/trust/conversion
- Blot slicing the material fish
- Blot leading the handoff path
- Blot pulling three layers of information sources
- Three Blots each holding a megaphone/building a bridge/opening a door
- Blot stamping the copy toolbox
- Blot holding a sign looking at the common-pitfalls path

Use a new metaphor even for the same kind of topic. For example, a "handoff path" doesn't have to be drawn as a route — it can be Blot attaching the tail of the content to a door handle; "one fish many uses" doesn't have to be a fish — it can be Blot pressing one paper ball into several shapes.
