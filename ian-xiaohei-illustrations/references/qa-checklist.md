# QA Checklist

## Must pass

- It is 16:9 landscape.
- The background is a clean white base.
- Blot is present.
- Blot carries the core action, not just decoration.
- No old case composition is reproduced; a new metaphor was generated for the current article.
- The frame is weird, creative, interesting.
- Clean and uncrowded; the main subject is no more than ~60% of the frame.
- One image conveys only one core structure.
- Labels are few, short, and readable.
- Orange is used only for the main path or arrows.
- Red is used only for key points, problems, reminders, or results.
- Blue is used only for supplementary notes, feedback, or system state.

## Failure signals

If any of the following appear, regenerate or do a local edit:

- A title like "common pitfalls / Workflow / system architecture / roadmap" in the top-left.
- Blot looks like a mascot, emoji, or cute cartoon.
- The frame looks like a PPT, course slide, or formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text turns into long paragraphs of explanation.
- The background has paper texture, shadows, gradients, beige, or noise.
- A real UI screenshot or techy interface.
- Serious typos or unreadable labels.
- The frame is too stiff, with no absurd metaphor.
- Too similar to an old case composition in `assets/examples/`.

## How to iterate

- Too plain: make Blot the acting subject, add a strange-yet-coherent metaphor.
- Too complex: cut nodes, keep only one action and 3-5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT: remove the title, borders, neat grid, and excess arrows; switch to a hand-drawn scene.
- Too much like an old case: keep the core idea, swap the main object and Blot's action.
- Wrong text: prefer a local edit; if there are many errors, regenerate and reduce the number of labels.

## Delivery judgment

A high-quality image should make the reader first feel "a bit weird," then understand the structure within 1 second.

If the first glance looks like a tutorial page rather than a weird product sketch on blank paper, it fails.
